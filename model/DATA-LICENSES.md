# Data and licence manifest

`data/sources.json` is the allowlist; `data/source-lock.json` records what was actually retrieved and its SHA-256. An item with an unknown or incompatible licence must remain disabled.

## Current classes

- **Owned:** public Treasure Academy website knowledge base and original curriculum generated by this project. Ownership must be confirmed before any weight release.
- **US public domain / Project Gutenberg:** the underlying listed works are represented as public domain in the United States. The fetch pipeline removes Project Gutenberg headers/footers. Distribution outside the US needs jurisdiction review, and Project Gutenberg trademark/licence conditions still matter for raw files.
- **CC BY 4.0 / African Storybook:** title, creator, illustrator when stated, source and licence are retained. Attribution must accompany redistributed dataset derivatives and any public model release should receive a legal review.

## Deliberately excluded

Pupil records, parent data, private messages, credentials, assessment submissions, paid platforms, random textbooks, copied exam banks and pages without affirmative reuse permission.

This file documents engineering controls, not legal advice.
